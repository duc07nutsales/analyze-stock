# Nội dung yêu cầu

1. **Code các phần tương ứng với các bài từ bài giảng số 4 trở đi**, bao gồm:
   1. Nhập xuất dữ liệu.
   2. Tiền xử lý, làm sạch dữ liệu.
   3. Biến đổi dữ liệu để phân tích.
   4. Vẽ biểu đồ trực quan hóa dữ liệu.
   5. *(Tùy chọn)* Sử dụng mô hình học máy để dự đoán kết quả từ dữ liệu.

2. **Tổng hợp kết quả từ code** thành các insight, gợi ý và trình bày một cách liền mạch, khoa học, trực quan; thể hiện được các xu hướng, kế hoạch phát triển, định hướng đầu tư, đặc điểm nổi bật hoặc dự đoán từ dữ liệu.

3. **Tổ chức code Python thành một báo cáo**, chia thành các phần tương ứng với các bài giảng lý thuyết, có giải thích, phân tích và thêm phần storytelling ở cuối.

4. **Chủ đề lựa chọn:**
   - **S&P 500 Stock Prices**
   - Historical stock market data for current S&P 500 companies from 2014–2017. Each record represents a single day of trading and includes the ticker name, volume, high, low, open and close prices.
   - **Dataset:** Included in the project folder.
